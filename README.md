# Bosque de números

Juego didáctico de estilo 16 bits para practicar la secuencia del 1 al 10.

Abrí `index.html` en un navegador para jugar. Tocá las manzanas numeradas en orden; cada acierto muestra su número en grande. Al completar la secuencia, podés iniciar otra partida.

El juego funciona como una página estática y no requiere instalación.
